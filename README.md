> ## ⚠️ This repository is archived and no longer maintained
>
> **Nylas Mail** (originally **N1**) was an open-source, extensible desktop mail client built on Electron, React, and Flux. It was released in 2015 and maintained by Nylas until 2017. This repository is preserved for historical reference and is no longer developed or supported.

## Looking for Nylas today?

Nylas is now the API platform that powers communications — connect Gmail, Microsoft, IMAP, and 250+ providers in minutes, or give an AI agent its own mailbox.
